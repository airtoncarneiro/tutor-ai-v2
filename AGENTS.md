# Instruções para implementação

Leia o README e todos os documentos normativos de docs/ antes de implementar a primeira tarefa. Execute as tarefas de docs/tasks.md em ordem de dependência, informando o escopo e a validação de cada entrega.

- Preserve Python, Streamlit, PostgreSQL local, single-user e uma sessão ativa.
- Preserve a política A–F, o perfil entre objetivos e a separação Run/Submit.
- Não substitua a geração por LLM por um catálogo fixo; catálogo é contingência.
- Não execute DDL fornecido livremente pelo LLM. Compile apenas o contrato validado.
- Tipos/capacidades desconhecidos falham explicitamente; não ignore restrições.
- Alterações de contrato incluem exemplos, migração quando necessária e testes.
- Não marque tarefa pronta sem seu critério de aceite. Diferencie validação com fake LLM de integração real com provedor.
- Não altere arquivos do usuário ou o índice Git fora do escopo. Commit, deploy e execução de infraestrutura não são implicados pela edição destes documentos.
